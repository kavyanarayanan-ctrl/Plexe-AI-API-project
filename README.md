## Overview

This project explored the end to end lifecycle of building, training, exposing and validating an AI model through APIs.

## Problem

Organizations need a fast way to validate AI capabilities before committing to full scale product investments.

## Users
Product Managers
Data Scientists
Engineering Teams

## Solution
The project demonstrated how an AI model can be trained, exposed through APIs and tested to validate business and technical feasibility.
